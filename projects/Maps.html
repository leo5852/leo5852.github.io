Project 3

지도 서비스 ·

프로젝트 소개

3인 팀 프로젝트 · 약 5개월

설정한 지표를 기준으로 최대 8인 온라인 대전을 지원하며, 팀 프로젝트(3인)로 약 5개월간 진행했습니다.

사용 기술

Unreal Engine 5 C++ Blueprint OpenStreetMap AWS EC2

내 역할

네트워크 동기화(Replication) 구조 설계 및 구현

캐릭터 이동·사격 입력 처리 및 서버 검증 로직

게임모드·게임스테이트 설계 (점수, 라운드 시스템)

기술적 특이사항

Client-Side Prediction + Server Reconciliation 구현으로 체감 지연 최소화

Lag Compensation(히트박스 되감기) 적용으로 고핑 환경에서도 공정한 판정

Nanite + Lumen 설정 최적화로 목표 60fps 달성 (4K 기준 PC 미드레인지)
