Project 2

3D 렌더링 엔진 · DirectX 12 · 2023

프로젝트 소개

DirectX 12를 사용해 직접 구현한 3D 렌더링 엔진입니다. PBR 재질 시스템, 그림자 매핑, 포스트 프로세싱 파이프라인을 포함합니다. 개인 프로젝트로 약 4개월간 진행했습니다.

사용 기술

C++ DirectX 12 HLSL ImGui Assimp

내 역할

  • 렌더링 파이프라인 전체 설계 및 구현 (개인 프로젝트)
  • PBR(Physically Based Rendering) 셰이더 작성
  • Cascaded Shadow Map 구현
  • ImGui 기반 실시간 파라미터 조정 도구 제작

기술적 특이사항

  • Deferred Rendering + Tiled Light Culling으로 광원 100개 이상 동시 처리
  • GPU 타임스탬프 쿼리로 드로우패스별 병목 구간 프로파일링 툴 구현
  • Resource Descriptor Heap 관리 자동화로 바인딩 오류 방지
