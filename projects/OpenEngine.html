OpenEngine 진행중

3D · Game Engine · C++17 · OpenGL

프로젝트 소개

개인 프로젝트 · 2025.12 ~ 진행중

 상용 엔진이 내부에서 해 주는 일을 직접 이해하기 위해 C++17과 OpenGL로 처음부터 만들고 있는 개인 3D 엔진입니다. 셰이더 로딩, 카메라, 조명 같은 렌더링 기초부터 충돌 검사와 강체 물리까지 한 단계씩 구현하고 있습니다.
 현재는 Jolt Physics를 통합해, 1인칭 플레이어가 3D 공간을 걸어 다니며 떨어지는 상자를 밀거나 계단과 경사를 오를 수 있는 단계까지 진행했습니다.

Technical issues

OBB 충돌 검사(SAT)와 충격량 기반 solver 직접 구현

회전한 상자끼리의 충돌을 처리하기 위해 15개의 분리축으로 검사하는 SAT를 구현하고, AABB는 사전 검사로만 사용했습니다. 상대 상자에 파고든 꼭짓점을 접촉점으로 잡아 접촉점마다 충격량과 마찰을 적용했고, 무게중심에서 벗어난 충격량이 회전을 만들어 비스듬히 떨어진 상자가 넘어지며 평평한 면으로 착지하도록 했습니다.

지터링 버그 추적과 해결

바닥에 놓인 물체가 계속 떨리는 문제가 있었습니다. 충돌 보정 과정을 추적해 원인을 찾아 수정했고, 이어서 최소 이동 벡터(MTV)의 방향을 콜라이더의 실제 중심 기준으로 계산하도록 개선했습니다.

자체 물리에서 Jolt Physics로 전환

계단, 경사, 물체 밀기처럼 필요한 기능이 늘어나자 자체 충돌 시스템을 Jolt Physics로 전면 교체했습니다. 초기화와 정리 순서를 PhysicsWorld 래퍼로 캡슐화하고, 60Hz 고정 타임스텝 누적기로 프레임 속도와 무관하게 물리를 갱신합니다. 플레이어는 CharacterVirtual로 바꿔 계단 오르기와 경사 처리를 지원하고, GLM과 Jolt의 쿼터니언 성분 순서 차이도 변환 함수로 정리했습니다.

셰이더 #define 주입과 다중 조명

최대 조명 개수 같은 값을 C++ 코드 한 곳에서 정하고 셰이더에 주입하도록, 셰이더 소스를 읽을 때 #version 바로 아래에 #define을 끼워 넣는 기능을 만들었습니다. 줄이 추가되며 컴파일 에러의 줄 번호가 어긋나는 문제는 #line 지시문으로 원본 파일과 맞췄습니다. 조명은 뷰 공간에서 계산하며, 같은 코드로 점광원과 방향광을 모두 처리합니다.

MSVC 빌드 설정 충돌 해결

Jolt를 서브모듈로 붙이자 런타임 라이브러리(/MD와 /MT)와 RTTI 설정이 엔진과 달라 링크 에러(LNK2038)가 발생했습니다. CMake에서 Jolt의 빌드 옵션을 엔진 설정에 맞춰 지정해 해결했고, Debug/Release 프리셋을 나눠 빌드 환경을 정리했습니다.
