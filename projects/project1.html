Project 1

2D 액션 RPG · Unity · 2024

프로젝트 소개

Unity로 개발한 2D 액션 RPG입니다. 플레이어는 다양한 몬스터와 전투하며 스킬을 성장시켜 나갑니다. 약 6개월간 팀 프로젝트로 진행되었습니다.

사용 기술

Unity 2022 C# Photon PUN Animator Git

내 역할

  • 전투 시스템 및 스킬 트리 설계 · 구현
  • 적 AI 상태머신(State Machine) 구현
  • 씬 전환 및 세이브/로드 시스템 구현

기술적 특이사항

  • ECS(Entity-Component-System) 패턴을 활용해 몬스터 오브젝트 풀링 구현, 드로우콜 40% 감소
  • 커스텀 A* 병렬 경로 탐색으로 다수 적 동시 이동 시 성능 최적화
  • ScriptableObject 기반 스킬 데이터 구조로 기획자와의 협업 효율 개선
