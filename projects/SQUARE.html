Project 1

2D 액션 RPG · Unity · 2024

프로젝트 소개

Unity로 개발한 2D 퍼즐 플랫포머 게임입니다. . 프로그래밍, 기획, 아트 담당이 나뉜 팀 단위 프로젝트로 진행되었습니다. 실제 Steam 출시까지 완료되었으며, 출시 후에도 지속적인 bug fix와 업데이트가 이뤄지고 있습니다.

사용 기술

Unity 2022 C# Git

역할

  • 일부 아이템 기능 구현
  • UI programming 담당
  • 세이브/로드 시스템 구현
  • sprite animation 적용
  • map editor 기능 구현

기술적 특이사항

  • MVC패턴을 적용해 구현한 map editor 기능
  • 커스텀 A* 병렬 경로 탐색으로 다수 적 동시 이동 시 성능 최적화
  • ScriptableObject 기반 스킬 데이터 구조로 기획자와의 협업 효율 개선
